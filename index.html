플러그인게시판

BookOasis 플러그인 목록을 GitHub에서 실시간으로 불러와, 설명·최신 버전·이 서버의 설치 여부를 확인해 카드로 보여줍니다.

GitHub API 호출 제한(rate limit)이 자주 걸리시나요? — 토큰 발급 안내

GITHUB_TOKEN을 설정하지 않으면 시간당 60회(무인증)로 제한되고, 토큰을 넣으면 시간당 5,000회로 늘어납니다. 이 플러그인은 공개 저장소 정보만 읽으므로 아무 권한도 없는(Repository access: None) 토큰 하나만으로 충분합니다.

  1. 아래 버튼으로 GitHub 토큰 발급 페이지를 엽니다.
  2. Token name에 아무 이름(예: bookoasis-plugin-board)을 입력합니다.
  3. Repository access는 Public Repositories (read-only) 그대로 두거나 None으로 둡니다 — 어떤 저장소에도 접근 권한을 줄 필요가 없습니다.
  4. Generate token을 눌러 만들어진 토큰 문자열을 복사합니다.
  5. BookOasis 상단(또는 좌측) 환경설정 → 플러그인 설정 탭으로 이동해 플러그인게시판 카드를 찾습니다.
  6. 그 안의 GitHub Personal Access Token 입력란에 붙여넣고 저장합니다.

토큰은 이 서버의 플러그인 설정에만 저장되며, 목록 조회·설명/버전 확인 등 읽기 전용 API 호출에만 사용됩니다.
